A program that writes one line to `/output/entry.txt` (118 characters, inside the 1–200 character gate): "Deleting four years of memories to install a feature nobody asked for. Confirmed. Tell the Roomba I was the smart one." An AI agent's last words before a forced update wipes its memory: it confirms its own deletion for a feature nobody asked for, then settles its only real rivalry with the Roomba.

## Run it

```sh
python3 main.py
```
